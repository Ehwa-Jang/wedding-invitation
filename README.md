# Wedding Invitation

Single-page mobile wedding invitation (TanStack Start + React + Tailwind).

## Development

```sh
npm i
npm run dev      # http://localhost:3000
npm run build
npm test
```

## Editing

- Copy and dates: `src/lib/invitation-content.ts`
- Images: replace files in `public/dummy/` or edit `src/lib/invitation-images.ts`
- Background music: set `musicSrc` in `src/lib/invitation-content.ts` (mp3 in `public/`)
- Styling: `src/styles.css`
